## 日志服务器安装
* 1.将日志服务器放在mc服务端执行程序目录
```
   服务器目录
     └───── bedrock_server
          ├─server.properties
          ├──neousf_config.json
          └───usf_manager.jar
```
* 2.运行
```
java -jar usf_manager.jar
```
